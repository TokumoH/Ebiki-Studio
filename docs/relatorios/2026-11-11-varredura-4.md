## Principais achados (detalhe no registro VER-2026-11-11-01)

1. **Popovers cortados/cobertos** — o popover de loop ficava dentro da barra com `overflow: hidden`
   (só uma faixa aparecia) e o menu do clipe era coberto pelos painéis de baixo. Os E2E passavam porque o
   Playwright rola contêineres escondidos; uma pessoa não consegue. Novo teste confere o que é visível.
2. **Renders desnecessários** — medido com contador temporário: 61 → 0 renders/s (Workspace parado,
   Mixer parado, Timeline tocando). Os medidores e o cursor agora atualizam só os próprios componentes.
3. **Disco** — caches nomeados pelo hash de áudios removidos nunca eram apagados.

## Sugestões pendentes (aguardam decisão)

**O que:** README nos ~80 diretórios de código restantes (`crates/*/src`, `tests`, `ui/src/*`).
**Solução:** um README por crate e por camada da UI (≈ 25), com "Onde" gerado por script a partir dos
comentários de cabeçalho dos arquivos; subpastas internas citadas no README do pai.
**Por que:** cumpre o objetivo da regra (orientar quem chega) sem dezenas de textos repetidos.
**Por que não um por pasta:** ~80 READMEs quase iguais (ex.: `src/` de cada crate) e alto custo de manutenção.
**Onde:** `crates/<crate>/README.md`, `ui/src/<camada>/README.md`. **Exemplo:** `crates/audio-engine/README.md`
listando `core.rs`, `graph.rs`, `input_tap.rs`… com a frase do `//!` de cada um.
*A regra atual do CLAUDE.md pede README em todo diretório; adotar esta alternativa muda a regra — por isso fica para decisão.*
